# Résumé Website Starter

## Files
- `index.html` — the page content and sections
- `style.css` — colors, layout, mobile responsiveness, and print styling
- `script.js` — mobile menu and Print / Save as PDF button

## How to open it
1. Download and unzip the folder.
2. Open `index.html` in a browser, or open the folder in VS Code.
3. If using VS Code, open `index.html` and use a local preview extension or open the file directly in your browser.

## Personalize before publishing
Search the files for `Your Name`, `your.email@example.com`, `Your City, State`, and sample profile links. Replace them with accurate information.
Review the education, certification, and project sections carefully. Keep only credentials and projects you actually completed. Add links to live projects or GitHub repositories if available.

## Use it for each job application
1. Keep this website as your general portfolio.
2. Read the job description and note the required skills, tools, and responsibilities.
3. Update a separate copy of your résumé for that job. Emphasize relevant skills and real examples; never claim skills or experience you do not have.
4. Save a tailored résumé as a PDF using the employer's requested format and filename, for example `YourName_WebDeveloper_Resume.pdf`.
5. Submit the requested résumé file and application through the employer's official application system. Include your website link only if allowed or requested.
6. Before submitting, check dates, spelling, links, contact details, and that the PDF opens correctly.
7. Track the job title, company, date applied, résumé version, and follow-up date in a simple spreadsheet.

## Important
A website is a supplement to an application, not a replacement for the employer's application form or résumé upload. Follow each employer's instructions. Some application systems do not accept portfolio links or website-only résumés.
